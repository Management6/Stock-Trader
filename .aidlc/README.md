# AI-DLC Local Scaffold

This directory is a placeholder for AI-DLC workflow content from
`awslabs/aidlc-workflows`.

Recommended setup:

1. Download the latest `ai-dlc-rules` release zip from the AWS Labs repository.
2. Copy the official `aidlc-rules/` folder into this directory.
3. Keep project-specific steering context in `.aidlc/project/`.

The full downloaded official rule bundle is ignored by Git in this starter
repository so future updates can overwrite it cleanly. The Amazon Q entry rule
is committed at `.amazonq/rules/ai-dlc.md`.
