# Problem Description

Build a Python foundation for a staged autonomous stock-trading system where
multiple AI-oriented agents divide responsibilities across discovery, data,
strategy design, backtesting, risk review, execution, experiment memory, audit
logging, and reporting.

The repository should favor clean architecture, visible decision records,
progressive autonomy, and safety controls over complex trading logic. It starts
with research and paper trading. Live execution remains disabled until explicit
guards, broker integration, Operations readiness, and human review exist.
