# AI-DLC Workflow Rule

When the user invokes AI-DLC, read and follow the official workflow rules from:

`.amazonq/rules/aws-aidlc-rules/core-workflow.md`

This repository intentionally includes only a lightweight project-specific
scaffold. To fully enable Amazon Q Developer with AI-DLC, download the latest
release from `awslabs/aidlc-workflows` and copy:

- `aidlc-rules/aws-aidlc-rules/` into `.amazonq/rules/aws-aidlc-rules/`
- `aidlc-rules/aws-aidlc-rule-details/` into `.amazonq/aws-aidlc-rule-details/`

Use the project steering files in `.aidlc/project/` and `docs/aidlc/` as the
domain context for this trading lab.
